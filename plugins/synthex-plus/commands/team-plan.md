# Team Plan (retired)

**synthex-plus is deprecated.** This command is a migration stub — it prints
the steps below and does nothing else. `team-plan` is retired outright, not
folded; `synthex` fans reviewers out the same way via its capability ladder.

Full guide: [`docs/migrations/synthex-plus.md`](../../../docs/migrations/synthex-plus.md).
